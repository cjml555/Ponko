Instalación y requisitos

Descargar el APK

La vía más rápida es la página de Releases: descarga app-release.apk y ábrelo en el teléfono (tendrás que permitir instalar desde esa fuente).

RequisitoValor
Arquitecturaarm64-v8a (solo 64-bit ARM)
Android mínimo9 (API 28)
Android objetivo16 (API 36)
Espacio libre~1–3 GB por modelo (varía)

Compilar desde el código

git clone https://github.com/cjml555/Yumenode-AI.git
cd Yumenode-AI
./gradlew assembleRelease
# Salida: app/build/outputs/apk/release/app-release-unsigned.apk
DependenciaVersión
JDK17
compileSdk / targetSdk36
minSdk28
NDK27.3
CMake3.31.6

Firmar

Los scripts de firma viven en tools/ y no contienen contraseñas: leen keystore.properties (ignorado por git) o la variable de entorno PONKO_KS_PASS.

powershell -ExecutionPolicy Bypass -File tools/sign-apk.ps1 \
  -Apk app\build\outputs\apk\release\app-release-unsigned.apk

Instalar por ADB

adb install -r app/build/outputs/apk/debug/app-debug.apk
Builds de debug: permiten HTTP en claro (necesario para apuntar el benchmark a un Worker local). Las builds de release exigen HTTPS.
