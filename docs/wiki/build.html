Compilar y desarrollar

Requisitos

HerramientaVersión
JDK17
Android SDKcompileSdk 36, build-tools recientes
NDK27.3
CMake3.31.6

Comandos habituales

./gradlew assembleDebug      # APK de debug (permite HTTP local)
./gradlew assembleRelease    # APK sin firmar
./gradlew test               # tests unitarios
./gradlew lint               # análisis estático

Estructura del proyecto

app/src/main/java/com/yumenode/ai/
  MainActivity.kt        UI, navegación y orquestación
  ChatCore.kt            motores de chat (llama.cpp / LiteRT)
  SettingsPage.kt        Ajustes: tema, idioma, benchmark
  ModelsPage.kt          modelos y backend
  DownloadPage.kt        catálogo y descargas
  ApiServer.kt           servidor OpenAI-compatible
  SegmentedSwitch.kt     control segmentado (tema/idioma)
app/src/main/cpp/        stable-diffusion.cpp, ggml, JNI
bench/worker/            Worker de benchmarks (Cloudflare)
docs/                    sitio (GitHub Pages) y esta wiki

Internacionalización

  • values/strings.xml: inglés (por defecto).
  • values-es/strings.xml: español completo.
  • values-zh/: chino.

Regla: no mezclar idiomas en values/. Todo texto nuevo va a recursos, no al código.

CI / releases

  • .github/workflows/release.yml: al empujar un tag v* compila, firma y publica APK + AAB.
  • El «version bump» se hace en el workflow y se empuja de vuelta a main.
git tag v1.2.0 && git push origin v1.2.0

Sitio y wiki

Todo lo que hay en docs/ se publica con GitHub Pages (main → /docs). Esta wiki son HTML estáticos en docs/wiki/.
