Generación de imágenes

Preparar el modelo

  1. Modelos/API → Draw model: elige el tipo (SD 1.x/2.x, SDXL, SD3, Flux, Qwen-Image, HiDream, vídeo u otro).
  2. Selecciona el archivo único o rellena los slots del modelo multi-archivo.
  3. Carga el modelo y espera; la primera vez tarda decenas de segundos.

Texto a imagen

AjusteRecomendación
TamañoMúltiplo de 64; 512×512 (SD1.5) o 1024×1024 (SDXL)
Pasos20 estándar; 4–8 con LCM-LoRA
CFG~7; 1.5–2 con LCM-LoRA
SamplerDPM++ 2M SDE, SDE B&T, LMS, Euler a…
Prompt negativoLo que no quieres ver
SemillaFija para reproducir el mismo resultado

Imagen a imagen

Elige una imagen de referencia y ajusta la intensidad de denoising (0.05–0.99): más baja = más fiel al original; más alta = más libertad creativa.

Aceleradores

  • LCM-LoRA: generación en pocos pasos (~5× más rápido). Requiere bajar pasos y CFG.
  • TAESD: autoencoder diminuto para vista previa y decodificación rápida. Para img2img usa pesos completos (codificador + decodificador).

Desde el chat

Con un modelo de chat y uno de dibujo cargados, escribe «dibuja un gato» en Chat: el modelo decide invocar el generador y el resultado aparece en la conversación.

Dónde quedan las imágenes

En la galería del sistema, carpeta Pictures/Yumenode AI. El historial interno de la página Dibujar es independiente y se puede borrar sin tocar las copias guardadas.

GPU (Vulkan): existe backend GPU, pero no está validado en dispositivos reales; si la inicialización falla, la app cae a CPU automáticamente y lo indica.
