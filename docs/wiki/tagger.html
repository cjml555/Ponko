Etiquetador

El tagger extrae etiquetas (tags) de una imagen usando un modelo ONNX local, sin subir nada a ningún sitio.

Importar el modelo

  1. Consigue un tagger estilo Danbooru (por ejemplo WD14) en .onnx y su lista selected_tags.csv.
  2. Modelos/API → Tagger: selecciona el .onnx y el .csv.
  3. Pulsa Cargar etiquetador (consume cientos de MB de RAM).

Etiquetar

ControlQué hace
UmbralConfianza mínima para aceptar una etiqueta (bájalo si salen pocas)
Máx. etiquetasRecorta la lista final
Orden de canalesLos modelos WD usan BGR; prueba RGB si los tags salen mal

Flujos útiles

  • Tagger → Imagen: envía las etiquetas como prompt positivo a texto-a-imagen o imagen-a-imagen.
  • Imagen → Tagger: usa una imagen generada como entrada.
  • Chat sin visión → Tagger: el modelo de chat pide prestado el tagger para «ver» la imagen.
El tagger no viene incluido ni se descarga automáticamente: los archivos se quedan en tu dispositivo y solo tú decides cuáles usar.
