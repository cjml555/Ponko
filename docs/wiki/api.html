API compatible con OpenAI

La app puede exponer el modelo cargado como una API HTTP compatible con OpenAI, para que otra máquina, un cliente de chat o un agente la use como si fuera un servidor remoto.

API de chat

MétodoRutaDescripción
POST/v1/chat/completionsChat con streaming SSE (stream:true) o respuesta completa
GET/v1/modelsModelo cargado actualmente
GET/healthEstado del servicio

Se arranca en Modelos/API → Chat model → API → Iniciar servicio. Puerto por defecto 8080; la clave Bearer es opcional (si no la pones, cualquiera que alcance la dirección puede usarla).

Ejemplo con curl

curl http://192.168.1.50:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TU_CLAVE" \
  -d '{"model":"local","messages":[{"role":"user","content":"Hola"}]}'

Ejemplo con el SDK de Python

from openai import OpenAI

client = OpenAI(base_url="http://192.168.1.50:8080/v1", api_key="TU_CLAVE")
r = client.chat.completions.create(
    model="local",
    messages=[{"role": "user", "content": "Explica un closure en 3 líneas"}],
)
print(r.choices[0].message.content)

Agentes locales

Herramientas como OpenCode o cualquier cliente compatible aceptan un proveedor «OpenAI-compatible». Ejemplo de configuración:

{
  "provider": {
    "yumenode": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "http://192.168.1.50:8080/v1", "apiKey": "TU_CLAVE" },
      "models": { "local": {} }
    }
  }
}

API de imágenes

POST /v1/images/generations devuelve b64_json. Está desactivada por defecto y es independiente de la de chat: su propio puerto, su propia clave y su propio interruptor. Los parámetros que el cliente no envía (pasos, CFG, tamaño, sampler, LoRA) usan los ajustes actuales de la página Dibujar.

Seguridad. El servidor escucha en todas las interfaces del teléfono. Sin clave, cualquiera en tu red puede consumir tu modelo y tu batería. Define una clave y úsalo en una red de confianza; exponerlo a internet es bajo tu responsabilidad.
La API se detiene al instalar una nueva versión o reiniciar el teléfono: vuelve a pulsar Iniciar servicio.
