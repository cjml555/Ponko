Qué hace

Todo el stack de IA, offline

Cinco pestañas: Chat, Modelos/API, Dibujar, Modelos libres y Ajustes. Todo corre en el teléfono, sin servidores.

💬

Chat multimodal

Modelos .gguf y .litertlm, streaming token a token, imágenes, archivos y documentos.

🎨

Generación de imágenes

Stable Diffusion GGUF: texto→imagen, imagen→imagen, LCM-LoRA y TAESD.

🏷️

Etiquetado automático

Taggers ONNX (WD14) que extraen etiquetas de tus imágenes, todo local.

🌐

API OpenAI-compatible

Expón el modelo cargado en /v1/chat/completions para usarlo desde otra máquina o un agente.

🔒

Privado por diseño

Sin cuenta ni telemetría automática. Nada sale del dispositivo salvo lo que tú decidas compartir.

📊

Benchmark transparente

Mide tok/s y latencia en tu hardware; comparte el resultado de forma anónima si quieres.
